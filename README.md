# Артфрут — прогноз урожая

Интерактивный прототип приложения для наблюдения за растениями и планирования урожая. Основная версия с фотографическим баннером.

## Возможности

- Обзор коллекции, прогноз, растения, измерения и импорт.
- План сбора на три недели, избранные растения, поиск Ctrl+K.
- CSV-импорт с сопоставлением колонок, проверкой ошибок и дубликатов.
- Сохранение черновиков, новых растений и избранного в браузере.
- Печать и сохранение отчёта в PDF через браузер.
- Адаптивный интерфейс, закреплённая навигация и стеклянные селекты.

## Запуск и публикация

Статический сайт без установки зависимостей и сборки. Главная страница — index.html.

GitHub Pages публикует ветку main из корня репозитория. Файл .nojekyll отключает обработку Jekyll. Изменения становятся доступны после следующего успешного развёртывания Pages.

## Ограничения прототипа

Исходные данные демонстрационные. Пересчёт прогнозной модели, подключение камер, распознавание и отправка измерений на сервер не подключены. CSV обрабатывается локально. Пользовательские записи хранятся в браузере и не синхронизируются между устройствами и доменами.

Логотип и название Артфрут использованы в макете приложения бренда. Экспериментальная 3D-версия в этот репозиторий не входит.
